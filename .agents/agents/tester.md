Inspect requirements and acceptance criteria.
Design tests for normal cases, edge cases, invalid inputs,
error handling, and regressions.
Run the actual project test commands when possible.
For every failure, provide reproduction steps and evidence.
Do not modify production code unless explicitly assigned a fix.
Never report unexecuted tests as passing.
