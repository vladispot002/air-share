# LAN-Drop Technical Specification

## 1. Загальний огляд
LAN-Drop — це високопродуктивна кросплатформна система передачі файлів для локальних мереж (LAN/Wi-Fi) з гібридною підтримкою зовнішніх хмарних релеїв (Cloud Relay).

## 2. Функціональні вимоги
- **Мережеве виявлення вузлів (Discovery)**:
  - UDP мультикаст маяки на порту 8848 (`LANDROP_BEACON|Name|UUID|Port`).
  - Фільтрація локальних пристроїв та хмарних ретрансляторів.
- **Швидке спарювання через NFC (NFC Quick-Pair)**:
  - Стандартний формат NDEF корисного навантаження: `LANDROP:NFC:v1;id=...;name=...;ip=...;port=...;pin=...;key=...`.
  - Автоматичне підключення та додавання вузла до списку пристроїв.
- **Apple AirDrop сумісність**:
  - Анонсування служби `_airdrop._tcp.local.` через Bonjour/mDNS.
  - Обробка запитів `/Discover` та `/Ask` з узгодженням блокової передачі.
- **Блокова передача та цілісність (Chunked Transfer)**:
  - Розбиття файлів на блоки фіксованого розміру (за замовчуванням 64 KB або 128 KB).
  - Контроль цілісності блоків та всього файлу за допомогою хешування SHA-256 (`FileChunkHasher`).
  - Підтримка докачування після розриву з'єднання (Resume).
- **Спільне сховище (Shared Folder Storage)**:
  - Сканування локальної директорії, індексація метаданих файлів, кількості блоків та контрольних сум.
  - Захист доступу через PIN-код або пароль.
- **Графічний інтерфейс (GUI)**:
  - Десктопний режим: macOS HIG (нативні traffic lights, сегментовані кнопки табів, картки пристроїв, інтерактивна таблиця передач, термінал діагностики).
  - Мобільний режим: вертикальна компоновка 390x812, нижня навігаційна панель, адаптивний стек.

## 3. Нефункціональні вимоги
- Мова програмування: C++20 (ISO/IEC 14882:2020).
- Графічна підсистема: GTK+ 3.0.
- Мережеві протоколи: POSIX sockets (TCP для передачі, UDP для маяків).
- Безпека пам'яті: RAII, відсутність ручного керування `new`/`delete` у бізнес-логіці, `std::shared_ptr`/`std::unique_ptr`.
- Продуктивність: передача великих файлів (10+ ГБ) без перевантаження оперативної пам'яті за рахунок стрімінгу блоків.
